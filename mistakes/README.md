# 📕 错题本

记录练习中出过的每一个错误。**错误是最 personalized 的学习资料**——考前/面试前只看这个文件夹就够了。

## 使用方式

1. 每章练习审读后，出错的题会记录为 `chNN.md`
2. 每条错题包含：错误代码原样、错因分析、正确写法、一句话教训
3. 重做：遮住"正确写法"，只看题目和错误代码，重新写一遍
4. 改正并通过测试后，把状态从 ⬜ 改为 ✅（Agent 审读确认后翻转）
